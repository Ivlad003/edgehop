One mouse and keyboard for all your computers

Push the cursor against the edge of the screen and it continues on the next computer, keyboard included. Works with any mouse and keyboard: Bluetooth, USB or built in.

Download for Windows Other systems

Windows · macOS · Linux — free, source code on GitHub

Any devices

No special mouse needed. The mouse and keyboard stay connected to one computer; the others receive them over the network.

Two computers or ten

Arrange the screens in a row the way they stand on your desk. A computer that is switched off is simply skipped.

No lag

Cursor motion travels over UDP, so a lost Wi-Fi packet never freezes the cursor. Processing takes less than a millisecond.

Encrypted

Everything you type is encrypted on the wire (X25519 + AES-256-GCM). No accounts, no cloud — only your local network.

One file

Nothing to install. Run the file and a settings page opens in your browser.

Shared clipboard

Copy text or files on one computer, move the cursor to another, and paste. Large files travel on a separate connection and never slow the mouse down.

Send files

Drop files or folders onto the edgehop page and they appear in the other computer's downloads folder. No size limit.

Remote windows (experimental)

Drag a window of a Windows computer past the edge of its screen and it opens as a window on the computer with the mouse: you see the same, and the mouse and keyboard in it work over there. From a Mac with the mouse, a window goes to another computer when you hold Ctrl+Option and take the cursor over the edge. Off until you turn it on.

Get started

  1. Download and run edgehop on every computer

    A settings page opens in the browser. It is reachable only from that computer.

  2. On the computer with the mouse choose “The mouse and keyboard are connected here”

    Arrange the screens from left to right and press “Save and start”. The page shows the address and the key for the other computers.

  3. On the others choose “This computer is controlled from another”

    Enter the address and the key from the first computer. Done: move the cursor past the edge of the screen.

Ctrl+Alt+Shift+Backspace always brings the cursor back to the computer with the mouse.

Download

Quick install from the terminal

macOS · Linux curl -fsSL https://raw.githubusercontent.com/Ivlad003/edgehop/main/install.sh | sh
Windows · PowerShell irm https://raw.githubusercontent.com/Ivlad003/edgehop/main/install.ps1 | iex

The script downloads the latest version for your computer, verifies its checksum and puts the program into your user folder — no administrator rights needed. Then start it with: edgehop

Or download the file yourself

Windows

x64 (Intel / AMD) ARM64

The file is not signed: if SmartScreen warns, click “More info” → “Run anyway”. On first start allow access in the firewall for private networks.

macOS

Apple Silicon (M1+) Intel

In Terminal, remove the quarantine flag and run it:

chmod +x edgehop-darwin-arm64
xattr -d com.apple.quarantine edgehop-darwin-arm64
./edgehop-darwin-arm64

Allow your terminal under Accessibility and Input Monitoring in System Settings → Privacy & Security.

Linux

x64 ARM64 
chmod +x edgehop-linux-amd64
./edgehop-linux-amd64

Needs access to /dev/uinput and /dev/input — how to grant it.

Project status

To be upfront: the project is young. Capturing and replaying the mouse and keyboard has been checked on a real Windows machine and by an automated test on a real Mac. On Linux it is verified at the kernel level, but not yet on a real desktop session. Nobody has run the whole thing across two separate computers yet, so a first run may reveal bugs.

Found a bug, or something does not work? Report it on GitHub.

  • Files are transferred by dropping them onto the edgehop page or by copy and paste; dragging a file with the mouse across the screen edge straight onto another computer is not possible. Images on the clipboard are not transferred yet.
  • Games that capture the mouse will not work on a controlled computer.
  • Ctrl+Alt+Del and Win+L always act on the computer with the keyboard.
